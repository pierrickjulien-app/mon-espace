# Mon Espace

Plateforme personnelle : Mon Intermittence, Mon Budget, Réservations et Mes Impôts.

- Application web installable (PC et smartphone : « Ajouter à l'écran d'accueil »).
- Aucune donnée personnelle dans ce dépôt : les données restent sur l'appareil
  et, une fois connecté à Google, dans un dossier caché de ton Google Drive.
- Google Agenda : lecture des événements et ajout automatique des activités.
